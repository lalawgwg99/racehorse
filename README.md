- 玩法：每天 6 場比賽（新馬戰 → 條件戰 → 公開賽 → G3 春季盃 → G2 夏季盃 → G1 天駒大賽），每場 8 匹馬，看五圍／場地距離適性／近況／賠率下注，看比賽動畫，結算領錢
